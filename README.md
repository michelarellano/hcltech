# HCLTech — Portal de solicitudes de hardware

Portal web interno para gestionar solicitudes de hardware en el IT Secure Room (ITSR) de HCLTech, edificio Minerva.

## Descripción
Sistema que permite a los empleados solicitar hardware (headsets, teclados, mouses, etc.), el SSRO aprobar o rechazar las solicitudes, y el equipo de IT registrar la entrega.

## Requisitos técnicos
Chrome o Microsoft Edge.

## Tecnologias
- Java 17
- Spring Boot 4.0.5
- Spring Security
- Spring Data JPA
- Spring Initialzr
- eclipse
- HeidiSQL
- Maven
- GitHub Actions
- Git Bash

## Roles
- EMPLEADO: crea y consulta sus solicitudes
- SSRO: aprueba o rechaza solicitudes
- IT: registra la entrega del hardware

## Fuera de alcance v1
- SSO corporativo
- Notificaciones por correo
- Control de inventario completo
